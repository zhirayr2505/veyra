# VEYRA — Asset Pack v2.0

**Новая самостоятельная дизайн-система для VEYRA Dating (Telegram Mini App).**

Оригинальные минималистичные материалы, созданные специально для VEYRA. Вдохновение — чистота и сценарии популярных dating-продуктов; без копирования знаков, шрифтов и защищённой графики Badoo.

**Цвет:** `#6817FF` фиолетовый · `#8F4AFF` вторичный · `#FF6A9B` акцент · `#25153D` текст · `#F9F7FF` фон.

## Содержимое

- `brand/` — новый векторный логотип VEYRA, символ, иконка Mini App, аватар Telegram, splash
- `icons/outline/` — самостоятельные системные SVG
- `icons/active/` — активные варианты тех же SVG
- `icons/on-dark/` — варианты для тёмных кнопок/фона
- `interests/` — интересы и хобби
- `gender/` — отдельные гендерные иконки (ink/purple)
- `illustrations/` — 20 оригинальных плоских иллюстраций для экранов
- `badges/` — бейджи Premium, Verified, New, Match, Owner и др.
- `tokens/` — CSS + JSON дизайн-токены
- `styles/` — переиспользуемые CSS-компоненты + motion
- `preview/` — автономная HTML-галерея всех элементов
- `tools/` — проверка SVG и ручная установка в `public/veyra-v2/`

**Важно:** текущие файлы старого приложения не затронуты. Это готовый исходный набор в корне репозитория для согласованной пересборки, а не новая опубликованная версия UI.

Смотри `USAGE.md` для подключений, маппинга экранов и этапов безопасной миграции.

## Быстрая проверка

node veyra-assets/tools/verify.mjs
