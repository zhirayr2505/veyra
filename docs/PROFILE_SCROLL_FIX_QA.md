# VEYRA — профиль: исправление и статус проверки (15.10.2026)

Источник: архив `VEYRA_PROFILE_TZ_AND_CODE.zip`, baseline `42d6019935fca39f7669be662dd2fe9387aa743e`.

## Изменения
- Один вертикальный контроллер; нативная инерция остаётся за scroll-контейнером; отпускание ниже диапазона шапки не сбрасывает прокрутку.
- Единые JS и WAAPI кадры; равномерная укладка изображения внутри аватара, сохранённый crossfade первого фото.
- Одна непрерывная белая панель, сетка интересов без конкурирующего `!important`, палитра через дизайн-токены.
- Единственный модуль профиля в `web/v5/profile/` с подкаталогами `motion`, `components`, `model`, `styles`.
- Дополнительное визуальное доведение: имя видно на всем пути; в промежуточной фазе оно располагается ниже изображения, кнопки временно скрываются, при сворачивании имя переходит в строку справа. Фотография при формировании круга не пересекает измеренную верхнюю зону логотипа с дополнительным безопасным отступом 12px.

## Контроль и непроверенное
- Unit-тесты с исходными математическими сценариями и новыми проверками safe-area/имени должны пройти в CI.
- Обязательные проверки перед слиянием: `npm ci`, `npm run check`, `npm run lint`, `npm run typecheck`, `npx playwright test`.
- Настоящий Playwright-профиль: скролл длинных интересов с отпусканием, быстрая смена направления, оба направления морфа, поворот экрана, галерея и horizontal swipe.
- На реальном Samsung Galaxy A55 внутри Telegram проверить 0.0-1.0 по шагам с прокруткой, безопасную зону нативной панели, срез лица, белую подложку и 60fps.
- MP4 `1000068301.mp4` не входит в исходный архив, доступен только подробный `02_VIDEO_AUDIT.md`. До повторного просмотра записи и реального UI профиль НЕ ПРИНЯТ.
